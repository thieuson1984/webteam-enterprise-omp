# OMP Runtime Self-Orchestration Audit

**Static inventory cannot prove runtime routing.** Verify exact OMP build/profile, active cwd, nearest `.omp` path and actual agent discovery. OMP native sources include `~/.omp/agent/agents/*.md`, `.omp/agents/*.md`, user/project `skills/*/SKILL.md` and `commands/*.md`; effective provider toggles and project overrides can shadow files.

**Read-only diagnostic gates:** `A` YAML parse and exact roster; `B` available models/routes; `C` commands and skill discovery; `D` actual permitted native `task` and child completion; `E` ordinary language request routes through WebTeam policy; `F` independent Reviewer results and evidence verification. Run D/E only with a user-approved synthetic safe fixture and inspect inherited headless tools; never widen permissions merely to make a test pass.

**Case handling:** tool absent or recursion restricted → MAIN coordinates direct verified specialists if possible; denied subagent → report blocked; no model route → maintain user-provided config and request choice; unexpected plugin/MCP → disable only with approval or stop. Include observed task IDs, agent/model, tool use, actual results and any missing checks.
